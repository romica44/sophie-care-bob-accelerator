## Project Title

SophieCare Bob Accelerator

## Short Description

A Bob-powered workflow that accelerates building, documenting, testing, and understanding SophieCare, an AI surgical co-pilot prototype.

## Long Description

SophieCare Bob Accelerator demonstrates how IBM Bob can help developers turn a complex software idea into a working proof of concept faster. The project uses SophieCare AI Surgical Co-Pilot as the target application: a healthcare AI prototype designed to support ophthalmology surgical training through simulated phase analysis, safety-aware feedback, and resident education workflows.

The main goal of this submission is not only to present a polished demo app, but to show how Bob acts as an AI-powered development partner throughout the build process. Bob is used to understand the repository context, explain the architecture, generate onboarding documentation, suggest tests, identify refactoring opportunities, and prepare the codebase for public review.

This approach directly addresses the hackathon challenge: reducing the repetitive work that slows developers down. With Bob, builders at different skill levels can understand an unfamiliar codebase faster, make safer improvements, and deliver higher-quality software with more confidence.

The demo application runs as a Next.js prototype and includes a surgical intelligence dashboard, mock AI outputs, agent reasoning traces, responsible AI disclaimers, and an IBM Bob evidence folder. The repository is prepared for the official exported Bob report, which will be added after IBM Bob access is provided during the event.
