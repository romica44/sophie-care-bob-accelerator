# 5-Minute Video Presentation Script

## 0:00–0:25 — Introduction

Hi, I’m Romina Cattaneo, and this is SophieCare Bob Accelerator. This project was created for the IBM Bob hackathon challenge: turn idea into impact faster.

The core idea is simple: developers spend too much time understanding unfamiliar code, writing documentation, planning tests, and preparing software for delivery. SophieCare Bob Accelerator shows how IBM Bob can reduce that friction.

## 0:25–1:10 — Problem

Building software is not only about writing code. Teams also need to understand architecture, onboard new developers, document decisions, identify missing tests, and safely improve existing code.

This becomes even harder in specialized domains like healthcare, where developers need both technical context and domain context before they can contribute confidently.

## 1:10–1:55 — Solution

SophieCare Bob Accelerator uses a realistic healthcare AI prototype as the target codebase: SophieCare AI Surgical Co-Pilot, a simulated ophthalmology training assistant.

The product demonstrates a surgical intelligence dashboard with phase analysis, safety-aware feedback, resident training insights, and responsible AI disclaimers.

But the main innovation is how IBM Bob is used as the development partner. Bob helps read the repository context, explain the codebase, generate onboarding documentation, suggest tests, identify refactoring opportunities, and prepare the project for delivery.

## 1:55–2:45 — Demo

Here is the live application deployed on Vercel.

The landing page explains the IBM Bob workflow. I can run the productivity review and see how the project is evaluated across Bob alignment, developer value, demo readiness, and business impact.

The dashboard shows productivity insights, submission risks, next steps, and an agent trace that maps the development workflow: repository understanding, documentation, testing, refactoring, healthcare context, and submission preparation.

## 2:45–3:35 — IBM Bob usage

The repository includes a dedicated IBM Bob Evidence Center under `docs/ibm-bob`.

Inside it, there is a task plan, prompt playbook, session log template, screenshot folder, and export folder for the official IBM Bob report.

Once IBM Bob credentials are provided, the workflow is ready: Bob will analyze the repository architecture, generate onboarding documentation, suggest tests, review maintainability, and validate final submission readiness. The exported Bob report will be added publicly so judges can inspect the actual Bob-assisted development process.

## 3:35–4:20 — Business value

This workflow can scale beyond this prototype. Any team working with complex repositories can use Bob to speed up onboarding, reduce repetitive documentation work, improve test planning, and support safer refactoring.

The healthcare AI use case shows how valuable this becomes in specialized industries, where code context and domain knowledge both matter.

## 4:20–4:50 — Future roadmap

Future versions can integrate real IBM Bob-assisted code transformations, automated test generation, deeper architecture reviews, and continuous repository documentation updates.

For the healthcare side, the SophieCare prototype can later connect to open-source computer vision models, RAG knowledge bases, and validated clinical datasets under proper medical supervision.

## 4:50–5:00 — Closing

SophieCare Bob Accelerator shows how IBM Bob can help builders move faster, understand better, and deliver higher-quality software with more confidence. Thank you.
