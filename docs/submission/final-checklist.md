# Final Submission Checklist

## Before publishing GitHub

- [ ] Run `npm install`
- [ ] Run `npm run typecheck`
- [ ] Run `npm run build`
- [ ] Confirm `.env.local` is not committed
- [ ] Confirm repository is public
- [ ] Confirm README includes IBM Bob usage
- [ ] Confirm `docs/ibm-bob/` exists
- [ ] Confirm `public/cover-16x9.jpg` exists

## After IBM Bob credentials arrive

- [ ] Open the repository with IBM Bob
- [ ] Run the prompts in `docs/ibm-bob/bob-prompt-playbook.md`
- [ ] Save meaningful outputs or screenshots
- [ ] Apply useful Bob-generated documentation or code improvements
- [ ] Commit Bob-assisted changes
- [ ] Export the official IBM Bob report
- [ ] Add the report to `docs/ibm-bob/exports/`
- [ ] Update README if the export filename is different

## Vercel deployment

- [ ] Push repository to GitHub
- [ ] Import project into Vercel
- [ ] Deploy with default Next.js settings
- [ ] Copy the live application URL
- [ ] Test the demo button on the deployed app
