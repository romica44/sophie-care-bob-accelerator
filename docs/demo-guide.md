# Demo Guide

## Demo objective

Show judges that the project is designed around IBM Bob as a development partner that accelerates repository understanding, documentation, testing, refactoring, and delivery readiness.

## Demo steps

1. Open the deployed Vercel app.
2. Explain that SophieCare is the realistic healthcare AI codebase.
3. Explain that IBM Bob is the development accelerator.
4. Click **Run Productivity Review**.
5. Walk through the scores:
   - Bob Alignment
   - Developer Value
   - Demo Readiness
   - Business Impact
6. Show productivity insights.
7. Show submission risks and next steps.
8. Show the agent trace.
9. Open GitHub and show:
   - `docs/ibm-bob/`
   - `docs/ibm-bob/bob-prompt-playbook.md`
   - `docs/ibm-bob/exports/`
10. Explain that the official exported Bob report will be added after credentials are provided.

## Judge-facing explanation

> This project does not use IBM Bob as a hidden detail. The full repository is structured to make Bob's development impact visible: prompts, task plan, evidence folder, session log template, and final report location are all public.
