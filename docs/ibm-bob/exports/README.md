# IBM Bob Exported Reports

Place the official exported IBM Bob report in this folder after using Bob during the hackathon.

Recommended filename:

```txt
ibm-bob-exported-report.pdf
```

Accepted alternatives, depending on the export format provided by IBM Bob:

```txt
ibm-bob-exported-report.md
ibm-bob-exported-report.json
ibm-bob-exported-report.html
```

Do not submit the project without adding the official report if the hackathon guide requires it.
