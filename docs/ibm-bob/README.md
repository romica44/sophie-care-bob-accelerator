# IBM Bob Evidence Center

This folder exists to make the project ready for the IBM Bob hackathon requirement.

The final submission must clearly demonstrate meaningful use of IBM Bob. Once IBM Bob access is available, run Bob against this repository, perform the task plan below, export the official Bob report, and place the exported file in:

```txt
docs/ibm-bob/exports/
```

Recommended final filename:

```txt
docs/ibm-bob/exports/ibm-bob-exported-report.pdf
```

If Bob exports Markdown, JSON, or another format, keep the original file and mention it in the repository README.

## What judges should see

- Bob was used directly on this codebase.
- Bob helped understand the repository context.
- Bob generated or improved documentation.
- Bob suggested tests and quality improvements.
- Bob helped identify refactoring opportunities.
- Bob's exported report is included publicly in the repository.

## Folder map

```txt
bob-task-plan.md              What to ask Bob to do
bob-prompt-playbook.md        Exact prompts to use once credentials arrive
bob-session-log-template.md   Manual log to keep while working
exports/                      Official exported IBM Bob report goes here
screenshots/                  Optional screenshots of Bob sessions
```
